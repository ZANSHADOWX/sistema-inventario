# Sistema de Control de Inventario

Repositorio oficial del proyecto **Sistema de Control de Inventario** desarrollado para la materia de Ingeniería en Desarrollo y Gestión de Software en Competencias Profesionales.

## Descripción

Este sistema permitirá:
- Registrar productos
- Consultar productos
- Modificar información de productos
- Eliminar productos
- Consultar existencias
- Registrar entradas y salidas de productos
- Generar un reporte básico de inventario

## Estructura del repositorio

- `docs/` → Documentación técnica del proyecto
- `src/` → Código fuente (se agregará posteriormente)
- `tests/` → Pruebas automatizadas (se agregará posteriormente)
- `.github/workflows/` → Configuración de CI/CD
